# Локальные изображения

`celebration/meme-01.png`–`meme-16.png` — пользовательские PNG из папки «Завершил тест, молодец», без изменения пикселей. Источник остаётся в исходной пользовательской папке. Приложение использует переносимые относительные пути.

Полёт управляется модулем `../celebration.js`. Для замены PNG и настройки количества см. README проекта. Загрузка каталога использует CSS-кота со спиннером. `favicon.svg` — знак проекта.
